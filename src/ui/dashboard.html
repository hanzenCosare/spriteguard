    Connect a GitHub repository

    Three steps. Nothing is written until a maintainer approves a verified patch.

    1. Add the webhook

    In your repo, open Settings → Webhooks → Add webhook. Set Content type to application/json and Secret to GITHUB_WEBHOOK_SECRET. Subscribe to Pull requests and Issue comments.

    2. Grant two separate connectors

    Read connector has contents:read, pull_requests:read, and metadata:read. It clones and audits inside isolated Sprites; raw tokens never enter Sprites.

    Write connector has contents:write, pull_requests:write, and issues:write. It only commits after /spriteguard approve.

    3. Use these in a PR comment

    /spriteguard approve
    /spriteguard rescan
